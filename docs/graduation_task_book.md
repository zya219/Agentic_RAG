# 毕业设计任务书

## 一、课题名称
**基于令牌级动作分解的 Agentic RAG 策略优化研究**

## 二、课题应达到的目的
本课题旨在构建一种面向 Agentic RAG（Agent-based Retrieval-Augmented Generation）的检索策略优化方法。通过引入令牌级动作分解（Token-level Action Decomposition）与强化学习策略优化，使语言模型能够更细粒度地控制检索行为，实现“何时检索”“检索什么”的自主决策，进而提升检索效率、生成质量与推理稳定性。

具体目标如下：

1. 构建可用于 Agentic RAG 的动作分解理论框架，使检索动作能够以 token 为单位进行建模与优化。
2. 设计并实现融合强化学习的检索策略优化算法，提升检索决策精度与信息利用效率。
3. 验证所提方法在检索效率、生成质量、过程可控性等方面的改进效果。
4. 最终形成包含创新方法设计、实验验证与可复现代码的完整研究成果。

## 三、课题任务的内容与要求

### （一）研究内容

1. **文献调研**
   - 系统调研 Agentic RAG、强化学习在语言模型中的应用、动作分解（POAD、NTPO 等）相关研究。
   - 总结现有方法的优势与不足，为改进方案提供理论基础。

2. **模型与算法设计**
   - 将检索行为抽象为工具使用动作，构建 token-level 行为建模方法。
   - 基于 POAD（Policy Optimization with Action Decomposition）思想，设计适用于 Agentic RAG 的策略优化算法。
   - 引入优势估计、价值函数等机制，实现对检索动作的细粒度信用分配（credit assignment）。

3. **系统搭建与实现**
   - 基于开源大模型（如 LLaMA/Qwen）与向量检索工具（如 FAISS 或 Elasticsearch）构建 Agentic RAG 系统。
   - 实现检索策略优化训练流程，包括数据构建、环境接口、策略训练等核心模块。

4. **实验设计与效果验证**
   - 在多项 QA / reasoning / RAG benchmark（如 HotpotQA、TriviaQA）上开展实验。
   - 分析检索频率、检索准确率、总体任务表现等指标。
   - 对比 baseline（如 ReAct、Search-R1、NTPO）验证本方法有效性。

5. **结果分析与总结**
   - 分析模型在不同任务场景中的性能差异，研究动作分解对检索效率与生成质量的影响。
   - 总结方法贡献、研究局限及未来发展方向。

### （二）任务实施要求

1. **理论要求**
   - 掌握大语言模型基础、强化学习基本原理与 RAG 框架结构。
   - 能够理解并复现 POAD、GLAM、NTPO 等相关算法。

2. **工程要求**
   - 熟练使用 Python、PyTorch 等深度学习工具，具备独立构建训练与推理系统的能力。
   - 能实现检索模块、策略网络、环境回合（episode）仿真等关键组件。

3. **文档与规范要求**
   - 所有实验需保持可复现性并提供代码。
   - 完成开题报告、中期检查、论文写作与最终答辩。
   - 论文格式符合学院规范，并附完整实验结果与图表。

## 四、课题成果要求

1. **技术成果**
   - 一个完整的 Agentic RAG 策略优化原型系统。
   - 经过训练的可复现模型与训练代码。
   - 实验数据与图表（如检索次数、检索效率、任务得分、消融研究等）。

2. **文档成果**
   - 文献综述。
   - 开题报告。
   - 中期报告。
   - 完整毕业论文。
   - 外文资料翻译。

3. **论文成果**
   - 清晰描述方法原理、算法流程、实验结果与创新点。
   - 能够对比相关工作并论证方法的有效性与先进性。
