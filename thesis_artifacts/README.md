# Thesis Experimental Artifacts

This directory contains experimental artifacts for the bachelor thesis:

**Research on Agentic RAG Strategy Optimization Based on Token-Level Action Decomposition**

## Contents

- baseline comparison summaries
- query-token decomposition debug results
- token reward visualization cases
- PPO Mini-run logs
- PPO-500 training metrics
- checkpoint evaluation summaries
- training curve data

Large files such as model weights, actor/critic checkpoints, Hugging Face caches, FAISS indices, and raw datasets are not included.

## Notes

The files are organized according to experiment stages and reward decomposition modes.
